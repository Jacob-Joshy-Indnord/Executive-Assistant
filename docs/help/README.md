# Executive Assistant: the guide

The Executive Assistant is a private desk for one manager. It keeps the manager's action
items, asks owners for updates, and reports where projects stand in words the owners have
confirmed.

It reports and prepares. It never decides. The manager decides, and owners speak for their
own work.

## Who are you?

- **You have an Executive Assistant.** Read [For managers](managers.md).
- **A manager asked you for something.** Read [For owners](owners.md).
- **You want to know what a mark on a statement means.** Read
  [Statement marks](statement-marks.md).

One person can be both: a manager with their own assistant, and an owner for other managers.
