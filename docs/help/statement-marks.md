# Statement marks

[Back to the guide](README.md)

Each line of a status report has a mark. It tells the manager whose words they are reading.

| Mark | What it means |
|---|---|
| **Confirmed** | The owner confirmed these words, or wrote them. |
| **Corrected by its owner** | The owner changed what the assistant drafted. These are the owner's words. The assistant's draft is kept but never shown. |
| **Awaiting confirmation** | The owner was asked again and has not answered yet. The line shows the last words the owner confirmed. |
| **No confirmed status yet** | No one has confirmed a status for this project yet. |

A confirmed statement cannot be changed. When an owner corrects it, the correction is added
as a new version and both versions are kept. The manager can see who corrected it, when, and
what changed.

Words that no owner has confirmed never appear in the manager's report.

See also: [For managers](managers.md) and [For owners](owners.md).
